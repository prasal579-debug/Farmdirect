# FarmDirect 🌾

FarmDirect is a farmer-to-supplier marketplace.

## Concept

Farmer → FarmDirect → Verified Supplier

## Main Features

- Farmer registration and login
- Supplier registration and login
- Farmer can list crops
- Suppliers can browse available crops
- Suppliers can make price offers
- Farmers can accept or reject offers
- Deal management
- Pickup tracking foundation
- Payment tracking foundation
- Ratings and reviews
- Admin dashboard foundation

## Technology

### Frontend
React + Vite

### Backend
Node.js + Express

### Database
SQLite

### Authentication
JWT
